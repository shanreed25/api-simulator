# API Simulator

>  A small application that leverages asynchronous API calls using Promises and implements error handling to ensure that the application can manage unexpected issues gracefully. Demonstrates the ability to work with asynchronous programming concepts, as well as managing errors effectively in a real-world scenario.

## How to Run

### Install the dependencies first

```bash
npm install
```

### Option 1: Use the start script to compile and run in one step

```bash
npm start
```

### Option 2: Compile and run separately

**Compile the TypeScript files into the `dist` folder:**

```bash
npx tsc
```

**Then run the compiled program:**

```bash
node dist/index.js
```
